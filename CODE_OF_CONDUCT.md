# Code of Conduct

## Notre engagement

Le projet DevCom CV Builder est un espace ouvert, respectueux et inclusif.

## Comportements attendus

- Respecter les autres membres
- Accepter les retours techniques avec professionnalisme
- Documenter les decisions importantes
- Aider les nouveaux contributeurs

## Comportements inacceptables

- Harcelement, insultes, menaces
- Discrimination (origine, genre, religion, etc.)
- Partage de donnees privees sans consentement
- Sabotage volontaire du travail collectif

## Application

Les mainteneurs peuvent moderer, refuser ou supprimer des contributions qui ne respectent pas ce code.

## Signalement

Signalez tout comportement inapproprie aux mainteneurs DevCom_UPL via le canal interne officiel WhatsApp.
